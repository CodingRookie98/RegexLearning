## [1.0.0] - 2026-02-20
### Added
- **Learn Module**: Comprehensive interactive courses for learning Regular Expressions step by step.
- **Question Bank Module**: Real-world Regex challenges with a built-in interactive validator to track mastery.
- **Playground Module**: Dedicated sandbox environment for testing regex patterns with real-time highlighting.
- **Cheat Sheet**: Interactive reference guide with collapsible categories and highlighted examples.
- **Internationalization (i18n)**: Full English and Simplified Chinese bilingual support, switchable in Settings.
- **Theming**: Elegant UI with Light, Dark, and System theme synchronization.
- **Local Progress Tracking**: Automatically saves learning progress and completed challenges tracking.
- **Desktop Client**: Packaged as a lightweight, native desktop application using Tauri.
